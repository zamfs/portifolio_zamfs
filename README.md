# Portfólio — Zamorano Sousa

Primeira versão em HTML, CSS, JavaScript e Bootstrap 5, baseada nas referências de `docs`.

## Como abrir

Abra `index.html` no navegador. Não é necessário instalar dependências ou compilar o projeto. Também é possível usar a extensão Live Server do VS Code.

## Onde editar

- `index.html`: textos, projetos, tecnologias e contatos. As seções estão identificadas com comentários.
- `css/style.css`: personalização visual, organizada em blocos numerados. As cores estão nas variáveis do início.
- `js/script.js`: atualização do ano e fechamento do menu no celular.
- `css/bootstrap.min.css` e `js/bootstrap.bundle.min.js`: Bootstrap local. Não é necessário editar esses arquivos.
- `docs`: referências originais, preservadas.

O grid e o menu responsivo usam Bootstrap. As prévias dos projetos são ilustrações em HTML e CSS, não capturas dos sistemas. As fontes do Google são opcionais: sem internet, o navegador usa fontes alternativas.
